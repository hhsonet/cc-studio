      GitHub sign-in and export

      The address people open in their browser, starting with https://. GitHub sends users back here after they approve.

      Paste this into your OAuth App at github.com → Settings → Developer settings → OAuth Apps → Authorization callback URL.

      Generate it on the same OAuth App page (“Generate a new client secret”). It is shown once by GitHub, stored encrypted here, and never displayed again. Leave the box empty to keep the saved one.

      What users are asked for when they connect GitHub for push and pull. Signing in alone asks only for their public profile. A change applies to users who connect after it.

      How to set it up

      1. Open github.com → Settings → Developer settings → OAuth Apps → cc-studio.
      2. Type your public address above and click Save. Copy the callback URL it shows into Authorization callback URL, and save the app on GitHub.
      3. On GitHub, click Generate a new client secret, copy it, and paste it into Client secret here. Check the Client ID too, then click Save.
      4. Open the login dialog in another window. Continue with GitHub should now take users to GitHub's Authorize page, with no code to type.

      Until a client secret is saved, GitHub sign-in falls back to typing a short code on github.com. Changes apply right away, with no restart.
